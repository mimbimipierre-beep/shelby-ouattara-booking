# Shelby Ouattara — Booking

Landing page complète de présentation et de booking de Shelby Ouattara, pour Zion Tour.

## Contenu

- Page responsive `index.html`, biographie, galerie de sept photos et clip Shine intégré.
- Dossier de presse PDF téléchargeable.
- Contact : booking@zionworld.fr et WhatsApp +32 466 33 79 32.
- Formulaire préparant une demande dans la messagerie du visiteur ; aucun serveur d’envoi n’est nécessaire.

## Déploiement

Site statique sans dépendances ni compilation. Sur Vercel : choisir Other, laisser la commande de build vide et servir la racine du dépôt.

Pour un aperçu local : `python3 -m http.server 8000`.

Site de référence : https://shelby-ouattara-booking.valeursafricaines-co.chatgpt.site/
